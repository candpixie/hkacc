# Hong Kong Arts and Culture Club at NYU

Site for HKACC, a new arts and culture club forming at New York University,
organised around the film, literature, music, comics, and language of Hong Kong
and the Cantonese-speaking world.

Static site. No build step.

```
python3 -m http.server 4321
```

## Status

HKACC is an applicant to the NYU Student Activities Board New Club Development
Program (Fall 2026). It is not yet a recognised NYU club and is not affiliated
with or endorsed by New York University yet.
